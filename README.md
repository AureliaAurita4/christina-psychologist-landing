# Лендинг Кристины Оразмурадовой

Одностраничный сайт психолога, созданный на React и Vite. Проект независим от старого Angular-приложения; из него перенесены только согласованные тексты и изображения.

## Локальная разработка

```bash
npm install
npm run dev
```

## Проверки

```bash
npm run lint
npm run build
```

## Контент

Основной редактируемый контент находится в `src/data/content.js`. Значения с комментарием `TODO: confirm` необходимо подтвердить перед публикацией.

После получения актуальных контактов заполните объект `contacts`. Перед публикацией также замените временный URL изображения Open Graph в `index.html` на абсолютный URL развёрнутого сайта.
